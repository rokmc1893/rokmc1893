- 화면에 필요한 데이터를 연동해 측정 상태와 결과를 표시했다.
- 자세 측정과 판단 기준에 관한 논문·근거 자료를 조사하고, 기능 설계에 참고할 내용을 정리했다.

### 오더십(OrderShip)

선박 견적 요구사양을 분석해 기자재 후보·호환성·근거·확인 질문을 정리하는 Upstage Studio 프로젝트다.

**담당 경험** · 워크플로우 공동 설계·개선, 테스트·오류 분석, 웹앱 연동·배포

- 워크플로우·테스트셋을 공동 담당하고, 경로별 판정·수량 차이·후보 오류 처리 수정안을 정리했다.
- Studio 결과 조회·보고서·PDF와 Netlify 데모를 연결하고 제출자료·검증 문서를 정리했다.
- 20세트 기대값 기반 검증과 실제 실행 결과를 구분해 기록했다.

**프로젝트 사용 기술** · Upstage Studio · React · TypeScript · Fastify · Playwright · Netlify<br>
<sub>백수해적단 팀 프로젝트 · 코드 비공개</sub>

### 오토일지(AutoDiary)

현대자동차그룹 차량용 앱 개발 공모전을 위해 외근 차량의 출발·방문·음성 메모·마감을 연결하도록 개발한 Android 프로토타입이다.

**담당 경험** · 제품 흐름 설계, AI 보조 개발·통합 검증, 시연 산출물 정리

- 차량 신호 기반 7단계와 SIM 시연 범위를 정하고 Compose 화면·상태기계·Room 저장·복구를 연결했다.
- 테스트 59건·SIM 빌드·APK 서명을 검증하고, 실제 차량 SDK·내비·음성 인식의 미검증 범위를 구분했다.

**프로젝트 사용 기술** · Kotlin · Jetpack Compose · Room · Android TTS/STT<br>
<sub><a href="https://appdevchallenge.auto-hmg.io/guide/submission#resubmit">현대자동차그룹 차량용 앱 개발 공모전</a> 참가 · 코드 비공개 · 차량 신호는 SIM 검증</sub>
