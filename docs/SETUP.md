# 프로필 관리 안내

이 저장소는 GitHub 프로필과 포트폴리오 웹페이지를 제공한다.

## 주요 파일

- `README.md`는 GitHub 프로필의 소개·수상·대표 프로젝트를 표시한다.
- `assets/profile-header.svg`는 밝은 테마와 어두운 테마를 지원하는 정적 소개 배너다.
- `index.html`은 같은 내용의 반응형 포트폴리오 웹페이지다. 별도 설치나 빌드 없이 열린다.

## 내용 수정

수상명과 담당 경험을 갱신할 때는 `README.md`와 `index.html`을 함께 수정한다. 프로젝트에 사용된 기술은 개인의 숙련도와 구분해 표시한다. 팀 전체의 구현 범위를 개인의 담당 경험으로 옮기지 않는다.

교육·동아리·참가 활동 목록은 표시하지 않는다. 공개되지 않은 프로젝트는 저장소 링크 없이 소개한다.

## 표시 확인

로컬에서 `python3 -m http.server 8000`으로 열고 밝은·어두운 테마와 모바일 화면을 확인한다. README는 GitHub에서 최종 표시를 확인한다. 소개 문구를 바꾸면 SVG 접근성 설명과 README 이미지의 alt도 함께 수정한다.

## 기존 통계 자동화

`.github/workflows/profile.yml`과 `scripts/update-cards.py`는 기존 기여 그래프·통계 이미지 갱신 설정이다. 새 프로필은 해당 이미지를 사용하지 않는다. 기존 자동화의 설정과 생성 파일은 보존한다.
